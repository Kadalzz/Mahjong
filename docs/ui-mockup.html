Sistem Booking Meja Mahjong — Tampilan Final

Rekreasi 1:1 dari tampilan yang sudah diimplementasikan di kode (token warna, komponen, dan tata letak diambil langsung dari layouts/app.blade.php & layouts/dashboard.blade.php) — bukan konsep baru. Berguna untuk ditinjau atau dipresentasikan tanpa perlu menjalankan server Laravel.

Catatan teknis: font Inter & Bootstrap Icons di kode asli dimuat lewat CDN eksternal, jadi di file offline ini diganti dengan font sistem & ikon SVG inline yang setara secara visual. Grafik Chart.js direpresentasikan sebagai bar/line statis dengan proporsi & warna yang sama.
